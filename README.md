# Retro Pac‑Man with Twist

## Project Overview
A lightweight Pac‑Man clone with a **Chaos Mode** twist. The game randomly selects one of three chaos modes at the start of each session:

- **Maze** – walls become invisible and the maze layout switches every 10‑15 seconds.
- **Ghost** – ghosts move faster and extra ghosts appear.
- **Vision** – a dark overlay limits visibility to a circular area around Pac‑Man.

The game includes a main menu, instructions, high‑score tracking, and optional sound effects.

## How to Run
1. Make sure you have **Python 3.13** (or later) installed.
2. Install the required dependency:
   ```bash
   pip install pygame
   ```
3. Clone the repository (or pull the latest changes) and navigate to the project folder:
   ```bash
   git clone https://github.com/Abrar-Siham/Retro-Pacman-with-Twist.git
   cd Retro-Pacman-with-Twist
   ```
4. Run the game:
   ```bash
   python main.py
   ```

Use the **arrow keys** to move Pac‑Man. Press **SPACE** on the Game Over screen to return to the main menu, or **ESC** to quit.
